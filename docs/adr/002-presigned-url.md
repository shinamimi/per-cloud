# ADR-002 — 文件访问方式：presigned URL 直连 MinIO

> 日期: 2026-07-31
> 状态: 已接受

## 背景

文件下载/预览需要决定对象访问链路：后端转发还是前端直连 MinIO。

## 方案对比

| 维度 | Presigned URL 重定向 | 后端流式转发 |
|------|---------------------|--------------|
| 后端带宽 | 不占，前端直连 MinIO | 全部经过后端 |
| 实现复杂度 | 生成签名 URL + 302 | 流式读写 + 断点处理 |
| 权限控制 | URL 有时效（10 分钟），过期即失效 | 每次请求实时校验 |
| 限速/日志 | 无法在后端做 | 可加限速、访问日志 |
| 单实例压力 | 极低 | 高 |

## 决策

下载/预览均生成 **presigned URL（有效期 10 分钟）→ 302 重定向**，前端直连 MinIO。

## 理由

1. 家庭/小规模部署场景后端带宽有限，直连避免流量瓶颈
2. 实现简单，无需自己处理 Range/断点
3. URL 时效天然提供访问控制

## 影响

- 后续多实例/集群部署时无状态，天然支持
- 如需审计下载日志，在生成 URL 时记录日志（后续决策）
