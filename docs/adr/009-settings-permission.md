# ADR-009 — 系统配置中心：两级权限分级

> 日期: 2026-07-31
> 状态: 已接受

## 背景

系统配置中心包含多类配置，其中 SMTP 连接信息（含密码）和系统功能开关（是否开放注册等）属于敏感配置，若 OPERATOR 可改存在安全风险。需确定配置权限分级。

## 方案对比

| 维度 | 全部 OPERATOR | 全部 ADMIN | 两级分级（本次决策） |
|------|--------------|-----------|---------------------|
| 操作便利 | 最高 | 低（OPERATOR 无法处理日常配置） | 平衡 |
| 安全 | 低（敏感项暴露给低权限） | 高 | 敏感项收紧 |
| 权限模型复杂度 | 低 | 低 | 中（逐项标记） |

## 决策

**两级权限**：

| 分组 | 可改角色 | 说明 |
|------|---------|------|
| 上传/存储/会话/缓存/文件/日志 | OPERATOR | 日常运维 |
| 系统功能开关、邮件服务（SMTP） | ADMIN | 敏感项 |

- OPERATOR 对敏感分组**只读展示**（禁用输入框）
- 后端接口同样校验角色（/settings/system、/settings/mail 限 ADMIN）
- 前端只读展示 + 后端拦截双保险

## 理由

1. OPERATOR 负责日常配置（上传限制、配额、日志保留），全部收走会导致运维效率低
2. SMTP 连接信息含密码、系统功能开关影响全局，收紧到 ADMIN 合理
3. 两级足够，无需为单项配置再细分（如 SMTP 密码单独 SUPER_ADMIN），保持模型简单

## 影响

- 配置项增加权限标记，后端分组接口按角色限制
- SMTP 密码等敏感值返回时脱敏，保存时二次确认
