# 管理后台 — 文件管理功能方案

## 一、功能边界

管理后台全局文件管理页，覆盖**个人文件 + 团队文件**，管理员统一管控。仅 ADMIN+ 可访问。

| 功能 | 说明 | 本次 |
|------|------|:----:|
| 全局文件浏览/搜索 | 个人+团队统一展示，多种筛选 | ✅ |
| 文件详情 | 所属用户/团队、大小、类型、路径、状态 | ✅ |
| 禁用/启用 | 禁用=用户可见但不可下载/预览/分享 | ✅ |
| 删除 | 进全局回收站（管理员可见） | ✅ |
| 全局回收站管理 | 浏览/恢复/彻底删除 | ✅ |
| 批量操作 | 多选禁用/删除 | ✅ |
| 管理员下载/预览 | 查看文件内容（含被禁文件，用于决定解禁；用户端统一拒绝） | ✅ |

## 二、权限分级

- **全部 ADMIN+** 可访问（浏览/删除/禁用均为 ADMIN）
- OPERATOR 不可见（无权限常规看不到）
- **前端路由守卫 + 后端权限校验双保险**，无权限不渲染入口

## 三、接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/files` | 文件列表（筛选+分页） |
| GET | `/api/admin/files/{id}` | 文件详情 |
| GET | `/api/admin/files/{id}/download` | 管理员下载（不受禁用限制） |
| GET | `/api/admin/files/{id}/preview` | 管理员预览（不受禁用限制） |
| PUT | `/api/admin/files/{id}/status` | 禁用/启用 |
| DELETE | `/api/admin/files/{id}` | 删除（进全局回收站，支持批量） |
| GET | `/api/admin/files/recycle-bin` | 全局回收站列表 |
| PUT | `/api/admin/files/recycle-bin/{id}/restore` | 恢复 |
| DELETE | `/api/admin/files/recycle-bin/{id}` | 彻底删除（支持批量） |

## 四、筛选条件

| 条件 | 说明 |
|------|------|
| 按用户 | 查看某用户的所有文件 |
| 按归属 | 个人文件 / 团队文件 |
| 按类型 | 图片/文档/视频/音频 |
| 按状态 | 正常/禁用/回收站 |
| 排序 | 大小/时间 |

## 五、操作语义

### 5.1 禁用/启用

- 禁用 = 用户仍可见该文件（列表可见），但**不可下载/预览/分享**
- 后端下载/预览/分享接口校验禁用状态，禁用文件拒绝访问
- 管理员可启用恢复

**用户端 vs 管理后台（下载/预览边界）：**

| 入口 | 被禁文件行为 |
|------|------------|
| 用户端个人/团队界面（任何用户，**包括管理员以用户身份登录**） | 下载/预览均拒绝（10216） |
| 管理后台（/api/admin/files） | 可**预览 + 下载**被禁文件，用于决定是否解禁 |

- 管理员不能在用户端界面下载/预览被禁文件（用户端接口对所有人统一拒绝）
- 管理员判断依据是管理后台的预览/下载，禁用=温和管控待核查，不阻断管理员审阅

**禁用粒度（管理员操作时选择影响范围）：**

| 范围 | 语义 | 影响 |
|------|------|------|
| 全站禁 | 禁用内容对象（hash） | 全站引用该内容的文件全部禁用 |
| 仅用户 | 用户×对象 | 只禁该用户对该内容，其他用户不受影响 |

- 对象级禁用记录落 `t_disabled_object`（file_hash × scope × user_id）
- 用户端下载/预览校验：文件 status=DISABLED，或内容 hash 命中对象级禁用（全站禁/该用户仅用户禁），均拒绝

**秒传/重新上传拦截：** 禁用记录在对象层，秒传或重新上传命中被禁对象时直接拦截，提示"上传违规文件"（10217）；秒传/普通上传（merge）命中被禁对象均拦截，不生成新文件记录。

### 5.2 删除

- 管理员删除 → 进**全局回收站**（仅管理员可见）
- 用户自删 → 进**用户私有回收站**（仅用户可见）
- 两个回收站独立，互不干扰

### 5.3 全局回收站

| 操作 | 权限 |
|------|------|
| 浏览 | ADMIN |
| 恢复管理员删的文件 | ADMIN |
| 彻底删除 | ADMIN |
| 删除用户的私有回收站内容 | ADMIN |

### 5.4 恢复权限

- **按删除来源恢复**：管理员删的 → 管理员恢复；用户自删的 → 用户恢复
- 管理员可删除用户的私有回收站内容（强制清理）

### 5.5 批量操作

- 多选文件批量禁用/删除
- 批量删除进全局回收站

## 七、前端

### 7.1 路由

```
/admin/files  →  AdminFileView.vue   （ADMIN+）
```

### 7.2 页面要素

- 筛选栏（用户/归属/类型/状态/排序）
- 文件列表表格（多选）
- 详情侧栏
- 批量操作栏（禁用/删除）
- 回收站 Tab（浏览/恢复/彻底删除）

### 7.3 路由守卫

- 前端路由 meta 标记 ADMIN+，无权限不渲染入口、路由拦截跳转
- 后端 SecurityConfig 同时校验（双保险）

## 八、需要做的事

### 后端
1. AdminFileController 扩展：列表筛选分页、详情、下载/预览、状态、批量删除、回收站 CRUD
2. File 实体/表新增**禁用状态**（如 FileStatus 加 DISABLED 或独立字段）
3. 下载/预览/分享接口校验禁用状态
4. 全局回收站：t_recycle_bin 增加删除来源标记（ADMIN_DELETED / USER_DELETED）
5. 权限：AdminFileController 全部 ADMIN+（SecurityConfig）
6. AdminTeamController 回收站复用（团队回收站与全局回收站管理）

### 前端
7. `views/admin/AdminFileView.vue`：列表+筛选+详情侧栏+批量操作+回收站 Tab
8. `api/admin/file.ts`：文件管理请求方法
9. 路由守卫：/admin/files 要求 ADMIN+
10. 操作日志：管理员禁用/删除文件记 OperationLog
