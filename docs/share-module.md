# 分享模块功能方案

> 对应 DDD 文档模块 M4 — 分享管理

## 一、功能边界

| 功能 | 说明 | 本次 |
|------|------|:----:|
| 创建分享 | 单文件 + 文件夹（快照锁定） | ✅ |
| 分享选项 | 有效期/提取码/允许转存/下载策略 | ✅ |
| 访客访问页 | 提取码验证 → 浏览/预览/下载/转存/批量下载 | ✅ |
| 我的分享管理 | 列表/取消/修改有效期/复制链接 | ✅ |
| 管理端分享管理 | ADMIN+ 查看所有分享、取消违规 | ✅ |
| 短码 token | 自定义 10 位去混淆字符集 | ✅ |

## 二、分享链接

```
https://{域名} / s / {token}
└─────域名──────┘ └─路径─┘
```

- **路径相对**：前端生成相对路径 `/s/{token}`，域名由环境配置决定，**换域名自动跟随**，无需改代码
- **token 短码**：10 位，去混淆字符集（排除 O/0/I/l/1），生成时查重防碰撞
- 详见 ADR-013

## 四、创建分享选项

| 选项 | 说明 |
|------|------|
| 有效期 | 永久 / 1天 / 7天 / 30天（上限由系统配置"分享最长有效期"限制） |
| 提取码 | 是否设置密码访问 |
| 允许转存 | 访客是否可转存到自己的网盘 |
| 下载策略 | **互斥单选**：允许下载（默认，可选次数限制）/ 禁止下载 |

### 4.1 下载策略互斥

- 禁止下载与下载次数限制**互斥**，UI 为单选组：
  - `允许下载（默认）` → 可选填"下载次数限制"
  - `禁止下载` → 不显示次数输入（只能在线预览）
- 默认值来自系统配置中心"文件管理"分组的"分享默认下载策略"（系统级，运营 OPERATOR 可配）
- 用户创建分享时基于默认值选择，可自行修改

### 4.2 文件夹分享（快照锁定）

- 分享文件夹 = 锁定**分享创建时的快照**
- 创建后文件夹内新增文件不影响已分享内容（更安全）
- 访客访问展示分享时锁定的目录树

## 五、访客访问流程

```
1. 访问 /s/{token}
2. 如设提取码 → 输入密码验证（错误限次 5 次，超限锁定需重新打开链接）
3. 浏览分享内容（文件/目录树）
4. 操作：预览 / 下载 / 批量打包下载 / 转存（需登录）
```

### 5.1 下载次数

- 每次**成功下载** +1，达到 maxDownload → 状态变 EXHAUSTED，不可再下载
- **转存不计数**（复制操作非下载）
- **计数语义：全局共享 N 次**——所有访客累计，用完全局失效（如 maxDownload=10，访客1 下 3 次 + 访客2 下 7 次即达限），而非每访客各自 N 次

### 5.2 转存

- 转存走**秒传**（引用计数 +1），不复制对象
- 需登录后才能转存

## 六、状态机

```
NORMAL → (过期) → EXPIRED
NORMAL → (取消) → CANCELED
NORMAL → (下载达限) → EXHAUSTED     ← 新增
```

## 十、需要做的事

### 后端
1. **token 生成器**：10 位去混淆短码 + 生成时查重
2. Share 创建逻辑扩展：文件夹快照锁定、下载策略、转存开关
3. 状态机新增 EXHAUSTED，下载成功计数
4. 提取码验证错误限次（Redis 计数）
5. 访客接口：文件/目录树/预览/下载/批量下载/转存
6. 转存走秒传 + 校验分享允许转存开关
7. AdminShareController：ADMIN+ 查看/取消
8. 系统配置中心"文件管理"分组新增"分享默认下载策略"

### 前端
9. `/s/{token}` 访客页：提取码输入/浏览/预览/下载/转存
10. `/shares` 我的分享页：创建/列表/取消/改有效期/复制链接
11. 创建分享弹窗：选项表单（有效期/提取码/下载策略互斥单选/转存开关）
12. `api/share.ts`
