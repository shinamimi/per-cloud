## 1. 文档说明

本文档在 PRD 基础上进行概要设计，将需求拆解为具体模块，定义各模块职责、边界、对外接口及协作关系，为详细设计和开发任务拆解提供依据。

适用范围：
- 后端：Java 21 + Spring Boot 4.0.7
- 前端：Vue 3 + TypeScript + Element Plus
- 存储：MySQL 8.4 + Redis 7.2 + MinIO

| M2 用户管理 | Y | | | | | | | | | Y |

说明：
- 所有模块依赖 M10 基础设施（配置、异常、工具类）
- M3 文件管理是核心，被 M4/M5/M6/M7 依赖
- M8 操作审计被所有关键操作模块依赖

### 3.2 协作场景

**上传文件**：用户 → F2 → M3 FileController → M10 鉴权 → M3 StorageService → M3 FileService → M8 审计 → M9 WebSocket

**创建分享**：用户 → F3 → M4 ShareController → M10 鉴权 → M3 FileService → M4 ShareService → M8 审计

**查看审计日志**：管理员 → F6 → M7 AdminController → M10 鉴权 → M8 OperationLogService → 返回日志

## 4. 安全设计

| 维度 | 设计 |
|------|------|
| 认证 | JWT 无状态，24h 过期，Redis 黑名单登出 |
| 授权 | Spring Security 角色粒度（USER/ADMIN/SUPER_ADMIN） |
| 密码 | BCrypt 加密，不可逆 |
| 登录保护 | 5 次失败锁定 15 分钟（Redis 计数） |
| 接口权限 | `/api/admin/**` 需 ADMIN 及以上角色 |
| 分享安全 | UUID Token，可选提取码 |
| 文件隔离 | 个人文件 `files/{userId}/`，团队文件 `files/team/{teamId}/` |
| 操作审计 | 全部关键操作记录 t_operation_log |

## 5. 部署架构

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│    Nginx     │────▶│  Spring Boot │────▶│    MySQL     │
│  (反向代理)  │     │  (Backend)   │     │    (8.4)     │
└──────────────┘     │              │     └──────────────┘
                     │  Java 21     │     ┌──────────────┐
                     │              │────▶│    Redis     │
┌──────────────┐     │              │     │    (7.2)     │
│  Vue 3 SPA   │────▶│              │     └──────────────┘
│  (Frontend)  │     │              │     ┌──────────────┐
└──────────────┘     │              │────▶│    MinIO     │
                     └──────────────┘     └──────────────┘
```

部署方式：Docker Compose（MySQL + Redis + MinIO 已编排），后端与前端分别构建 Docker 镜像，Nginx 统一入口。
